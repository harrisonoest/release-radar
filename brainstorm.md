# Release Radar

## Background

This is an application for tracking the music artists's in a user's library, checking for new releases by those artists, and adding the new releases to a playlist.

## Notes

- The streaming platform used is Apple Music
- Runs in the Linux CLI
- Uses the unique ID for artists to handle conflicts between artists that have the same name
- Should be super fast
